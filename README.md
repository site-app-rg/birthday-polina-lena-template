# Открытка Полины

Альтернативная версия на базе исходников открытки Лены. Исходный проект и другие варианты открытки Полины не изменены.

## Локальный запуск

```sh
npm ci
npm run dev
```

## Содержание

Используются 23 фотографии из `public/media`, включая `polina-13.jpg`, видео клиентки и текст её поздравления. Музыка сейчас отключена. Публикация выполняется через GitHub Pages после отправки в `main`.
